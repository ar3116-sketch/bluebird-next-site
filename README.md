# BLUEBIRD NEXT, inside

X-ray comparison of the BLUEBIRD survey UAV (rev C) and the BLUEBIRD NEXT concept: same wing, new insides.
Live page: https://ar3116-sketch.github.io/bluebird-next-site/

Static build output only. The renders (Blender Cycles from the project CAD) and `data.json` are generated in the
private project repo by `site/tools/render/xray_compare.sh`, and `site_next/deploy.sh` copies them here.
NEXT is a concept: the layout has been analysed, but nothing has been built or flown.
